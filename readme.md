## About

Peeknext is a professional text editor for macOS, built for responsive editing, large files, and local workflows.

- **Fast** — Low-latency editing, even with large files.
- **Local** — No accounts, telemetry, or internet connection required.
- **Scriptable** — Plain-text configuration, customizable keybindings, and Python commands.

## Getting started

Download the [latest release](https://github.com/peeknext/peeknext/releases/latest) for Apple Silicon Macs.

| Shortcut  | Action                    |
|-----------|---------------------------|
| `⌘O`      | Open file...              |
| `⌘W`      | Close file                |
| `⌘F`      | Find in file              |
| `⌘\`      | Toggle split editor       |
| `⌘⇧\`     | Buffer explorer           |
| `⌘P`      | File explorer             |
| `⌘⇧P`     | Command palette           |
| `⌘⇧F`     | Search explorer           |
| `⌘⇧↵`     | Run inline commands       |
| `⌘,`      | Open config file          |
| `⌘⇧,`     | Open scripts file         |

See the [documentation](https://peeknext.com/docs/) for more.

## Performance

Peeknext is benchmarked against popular editors using measured keypress-to-frame latency.

On a 60 Hz display, Peeknext achieved **16.6 ms P95 latency** on a 753,821-line source file, compared with 30.4 ms for Sublime Text, 57.3 ms for Zed, and 171.9 ms for VS Code.
