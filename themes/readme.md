# Themes

Color themes for Peeknext.

This directory contains a collection of light and dark themes.
Some are bundled with Peeknext, while additional themes are available here.

## Bundled themes

The following themes are included with Peeknext.

**Peeknext themes**

- Peeknext Dark
- Peeknext Light
- Peeknext Mono
- Peeknext Contrast
- Peeknext Midnight
- Peeknext Paper

**Other themes**

- Sublime Monokai
- GitHub Dark Dimmed
- GitHub Light
- One Dark Pro
- Catppuccin Mocha
- Tokyo Night
- Gruvbox Dark
- Solarized Light
- Ayu Mirage

## Installing themes

To install additional themes, copy the theme files into:

`~/Library/Application Support/Peeknext/themes/`

## Custom themes

Themes are plain-text configuration files that can be customized or used as starting points for new themes.

See the existing theme files for examples, or read the [documentation](https://peeknext.com/docs/).

## Contributing

Contributions of new themes and improvements to existing themes are welcome.

Please ensure that text, syntax highlighting, cursors, and selections remain readable.
